02 · The workflow

Approval is part of the architecture.

01ContractSwagger / OpenAPI input
02EvidenceCases, samples, pointers
03Human reviewSelect and approve
04Guarded runTarget and execution gates
05ResultRedacted record and summary

The core workflow is deterministic. Optional OpenAI drafting can add reviewer-facing scenario proposals within the same controlled process.

06 · Live Petstore read

Review one case before running it.

Fetch the current contract, then select only TC-GETINVENTORY-POS-200 and approve generation.

curl -fsSL https://petstore.swagger.io/v2/swagger.json -o /tmp/petstore-demo-swagger.json
npx tsx src/cli.ts guide \
  --spec /tmp/petstore-demo-swagger.json \
  --objective "Validate the Petstore inventory read operation" \
  --out tests/generated/petstore-demo-inventory.spec.ts \
  --audit /tmp/petstore-demo-guided.jsonl

Guide prompts: select the case ID, inspect evidence, type APPROVE. No API-under-test request yet.

What to point outExpected status, auth scheme, evidence pointer, and stable case ID. The generated artifact is tied to the approved plan revision.

11 · Trust and control

Make execution clear and controlled.

Reviewed generation

Generated tests are tied to the exact plan revision the reviewer approved.

Authorized targets

Target and authentication are confirmed before an API request is sent.

Mutation gates

State-changing tests require explicit opt-in and a separate run approval.

Traceable results

Stable case IDs and redacted reports make outcomes easier to review.

BenefitTeams can automate repeatable checks while keeping people in control of what runs and where.

12 / 15
12 · Optional AI-assisted drafting

Use an LLM to widen review, not own execution.

OpenAI can suggest additional scenarios from bounded contract context while the deterministic workflow remains the source of executable tests.

Bounded context

With explicit consent, send the objective and minimized, redacted operation summaries, documented statuses, and evidence pointers.

Proposal output

Drafts are written separately for manual review. Model-authored steps and code are never executed.

Grounded promotion

A draft may map to an exact eligible read-only case; the reviewer still selects and approves the new plan revision.

Current verification

Provider behavior and safety are covered by mocked tests. No live OpenAI request has been made.

Private specifications and objectives require an applicable data-policy review before external inference.
